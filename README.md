# drg-site

Сайт состава клана **DRG** + мод для Minecraft Fabric 26.2.

## 📦 Мод DRG Nametags

**Мод для DRG**

Мод показывает игроков находящих в клане и их должность с Discord.
Мод так же позволяет узнать Discord члена клана через TAB.

Список обновляется через минуту после добавления.

### Скачать

Файл мода лежит прямо в репозитории:

👉 **[drg-nametags-1.0.0.jar](drg-nametags-1.0.0.jar)**

(на странице GitHub нажмите на файл → кнопка «Download raw file», или прямая ссылка:
`https://github.com/TobbuuSad/drg-site/raw/main/drg-nametags-1.0.0.jar`)

### Установка

1. Нужен Minecraft **26.2** с Fabric Loader.
2. Положить jar в папку `mods` профиля.
3. Запустить игру — мод сам прочитает список с сайта
   (`config/drg-nametags.json` создаётся автоматически).
4. В чате появится: «DRG мод работает — база N игрок(ов), сборка …».

### Что делает

- Табличка над головой игрока из списка: **DRG**, должность, дискорд (цвет `#db20db`).
- В TAB после ника — Discord игрока из списка.
- Вставка (Insert) — включить/выключить надписи (меняется в `config/drg-nametags.json`).
