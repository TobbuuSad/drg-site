Таблица игроков мода DRG Nametags: ник в игре, должность и дискорд. Надпись над головой берётся отсюда.

🔐 Доступ к сайту

Просмотр состава — открыт для всех. Редактирование списка и публикация в GitHub доступны только после входа по логину и паролю. Учётные записи задаются в константе ACCESS_USERS в index.html.

Примечание: защита — программная, данные списка всё равно публичны в players.json. Реальную защиту правки в репозитории дают права токена GitHub.

Как это работает с модом. Мод раз в N минут (задаётся в config/drg-nametags.json, поле refreshSeconds) скачивает файл players.json по адресу из конфига (siteUrl) и помещает содержимое в свою локальную базу. Код мода при этом менять не нужно.

Как опубликовать изменения. Впиши токен один раз (🔑 Токен) — дальше всё автоматически: правишь список (добавить/изменить/удалить) — через 5 секунд файлы уходят в GitHub сами, статус виден рядом с кнопкой. Или нажми 🚀 сразу. Токен создать здесь: github.com/settings/personal-access-tokens/new (право Content: Read and write, только репозиторий drg-site).

Резервный способ без токена: «Сохранить оба файла» → положи их в папку сайта → запусти push.bat( или держи окно auto-push.bat открытым — оно отправляет само). Сайт обновляется через 1–2 мин после отправки.
