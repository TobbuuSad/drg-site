Как это работает с модом. Мод раз в N минут (задаётся в config/drg-nametags.json, поле refreshSeconds) скачивает файл players.json по адресу из конфига (siteUrl) и помещает содержимое в свою локальную базу. Код мода при этом менять не нужно.

Как опубликовать изменения. Отредактируйте таблицу выше, затем нажмите «Сохранить оба файла» и положите скачанные players.json и players.js на ваш хостинг (заменяя старые файлы). Варианты хостинга:

1) GitHub Pages: положите файлы сайта в репозиторий (Settings → Pages). неприхотливо и всегда онлайн;

2) Локально рядом с сервером: в папке сайта выполните python -m http.server 8000; в конфиге мода укажите http://IP-компьютера:8000/players.json;

3) любой другой статический хостинг — важно лишь, чтобы по адресу из конфига открывался players.json.

Адрес в браузере смотрится по адресу сайта, а мод читает именно players.json.
