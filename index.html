Как это работает с модом. Мод раз в N минут (задаётся в config/drg-nametags.json, поле refreshSeconds) скачивает файл players.json по адресу из конфига (siteUrl) и помещает содержимое в свою локальную базу. Код мода при этом менять не нужно.

Как опубликовать изменения. Отредактируйте таблицу выше, нажмите «Сохранить оба файла», затем положите файлы в папку сайта и запустите push.bat (он сам возьмёт свежие файлы из «Загрузок», сделает commit и отправит на GitHub). Либо правьте players.json прямо на странице репозитория GitHub (карандаш рядом с файлом). Через 1–2 минуты сайт обновится автоматически.
